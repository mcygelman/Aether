Advanced output checks

For several files, exact values or a team, supply a contract. Use solo for the lead alone. For a team, write a numbered plan in the brief and key the checks by the same task numbers: for example, "Add T1 to write RESEARCH.txt, then T2 to write SUMMARY.txt using T1", with checks 1 and 2. The lead numbers its tasks from 1 in the order it adds them, so the plan and the checks must agree. The server validates the checks; with a contract here, your brief goes to the lead unchanged.
