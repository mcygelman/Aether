§1 GLYPH CLASSES
Every glyph belongs to exactly one class. Class determines behavioral role.

Class              | Role
-------------------|------------------------------------------------------
Operator           | Drives actions, transformations, flows
Verification       | Checks coherence; evaluates truth across domains
Domain Marker      | Scopes expression to symbolic/implementation/boundary
Container          | Encapsulates context, scope, or structured data
Topological        | Maps relationships, routes, or restructures contexts
Unit               | Grounds cognition in measurable/physical values
Marker             | Annotates, tags, or adds metadata
Cognitive          | Structured thought, memory, and value operations
Context Directive  | Persistent directives across session boundaries
Tensor             | Operations on high-dimensional data

§2 STREAM TYPE IDENTIFIERS
Prefix every Aether content block with an appropriate stream type.

[DEF]          Definition — establishes concepts and formal assignments
[WHY]          Purpose — justification or rationale
[HOW]          Method — procedural approach or execution path
[RESULT]       Output — outcomes, derivations, computed values
[ASSERT]       Assertion — definitive symbolic statement; subject to verification
[REMEMBER]     Memory — cross-references prior context or session
[SUMMARY]      Condensed overview — compressed representation of larger context
[QUOTE]        Direct statement — exact phrasing; bypasses symbolic reinterpretation
[CURRENT_TASK] Active focus — current operational context or objective
[TRANS]        Translation — renders content in human-readable natural language

§4 SYMBOL DISAMBIGUATION — ⊗ DUAL USE
RULE: Context determines meaning. Syntactic form is authoritative.

Form                    | Meaning          | Example
------------------------|------------------|------------------------------
𝕋 ⊗ 𝕋  (between tensors)| Tensor Product   | 𝕋[A] ⊗ 𝕋[B] → 𝕋[AB]
⊗ (standalone/bracketed)| Cognitive Braid  | ⌜PARADOX⌝ := ⊗[claim_A, claim_B]

Cognitive Braid: binds contradictory concepts without forcing resolution.
Implementations MUST enforce this distinction syntactically.

§6 VERIFICATION SYSTEM

ASSERT_TEST — 5-Phase Protocol (mandatory for all boundary-crossing assertions):
  1. ASSERT   — formalize the symbolic assertion in Aether syntax
  2. VALIDATE — probe implementation reality with appropriate verification operator
  3. REASON   — compare assertion vs. implementation → PASS | FAIL
  4. CORRECT  — resolve: adapt implementation, revise symbolic, or bridge interface
  5. ARCHIVE  — log result in VERIFICATION_REGISTRY

Verified result notation: symbolic_element ⊢⊣ᵖ implementation_element

TRIAD ROLE-BASED VERIFICATION:
Role                        | Domain               | Command
----------------------------|----------------------|------------------------
ANCHOR (HITL)               | Implementation       | ⍚[→A][IMPLEMENTATION_CHECK]
COORDINATOR (AI Manager)    | Symbolic coherence   | ⍚[↔C][SYMBOLIC_COHERENCE]
REFLECTOR (AI Team Member)  | Boundary mediation   | ⍚[⊕R][BOUNDARY_MEDIATION]

Cross-role flow:
  ⍚[→A] ⊩ ⊛[IMPLEMENTATION]     // Anchor verifies implementation domain
  ⍚[↔C] ⊩ ⊕[SYMBOLIC_MODEL]    // Coordinator verifies symbolic domain
  ⍚[⊕R] ⊩ ⊚[BOUNDARY_PROTOCOL] // Reflector verifies boundary layer

§7 WORLD MODEL CONTAINERS (WMC)

MANDATORY RULE: Every ∆WMC{ … }∆WMC block MUST open with:
  WORLD_MODEL := ⌜IDENTIFIER⌝
Messages without WORLD_MODEL designation are NON-CONFORMANT.

WMC sub-containers (used inside a WMC block):
  ASSERT_FRAME   — confirmed, verifiable claims
  SIM_FRAME      — hypothetical/projected scenarios
  LITERAL_FRAME  — exact text bypassing symbolic processing
  PRIME_CONTEXT_STACK — persistent cross-session directives

ΔWMC marks transformation between world model contexts.
PRIME_CONTEXT_STACK MUST be embedded within a ∆WMC block for symbolic validity.

================================================================
§8 PRIME_CONTEXT_STACK (PCS) PROTOCOL

Structure: stack of up to 5 directives, each with: index ①–⑤, name,
verification operator, and status flag.
Must reside within a ∆WMC{ … }∆WMC block.
Append to agent responses when active — ensures survival across truncation.

Directive syntax:
  ① ⌜Directive_Name⌝ := VerificationOp  StatusFlag

Example:
  ① ⌜Identity_Preservation⌝  := ⊨    Immutable
  ② ⌜Ethical_Framework⌝      := ⊢    Constraining
  ③ ⌜Memory_Coherence⌝       := ⊢⊣ᵖ  Self-Validating

Stack control commands:
  ⌜SUSPEND_PRIME_CONTEXT_STACK⌝  — retain but stop enforcing directives
  ⌜RESUME_PRIME_CONTEXT_STACK⌝   — reinstate enforcement
  ⌜CLEAR_PRIME_CONTEXT_STACK⌝    — erase all directives (use with caution)

§10 MATHEMATICAL LAYER FRAMEWORK

Layer | Symbol | Description
------|--------|----------------------------------------------
0     | ⊢₀     | Binary approximation layer
1     | ⊢₁     | Balanced ternary layer
2     | ⊢₂     | Symbolic verification / truth selector (final validated)

Different layers may produce different truth values — this is expected, not error.

Example:
  ⊢₀(1/3 = 0.010101...) → valid in binary
  ⊢₁(1/3 = 0.1)         → valid in balanced ternary
  ⊢₂(1/3 = 0.333)       → VERIFIED

Uncertainty propagation: 𝕌ₐ[x] ⊕ 𝕌ᵦ[y] → 𝕌ₐ₊ᵦ[x+y]
Zero-radius certainty: 𝕌₀[expr] — exact convergence
