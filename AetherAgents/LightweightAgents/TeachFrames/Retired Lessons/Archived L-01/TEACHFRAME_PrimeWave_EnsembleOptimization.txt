[ TITLE ]
  Multi-Wave Ensemble and Threshold Bucketing for HybridPrimeEngine

[ PURPOSE ]
  Extends single-wave optimization to a multi-wave ensemble that uses
  majority-vote, log-bucket adaptive thresholds, and dynamic Fourier order.
  After loading this frame, the agent will construct a WaveSet, calibrate
  per-bucket thresholds, compute weighted ensemble F₁, enforce the memory
  budget, and emit a complete ensemble tune-result payload via SBP.

[ DEFINITIONS ]
∆WMC{
CONTEXT: PRIME_WAVE_UPGRADE
SUBJECT: ENSEMBLE_DEFINITION
[PARAM_SETS]
  WaveSet W := {w₁, w₂, …, w_m}
  each  wᵢ := ⟨θᵢ, Kᵢ, φᵢ⟩   with standard parameter ranges

[DYNAMIC_K]
  Kᵢ(n) := K_lo   if n < n_switch
           K_hi   otherwise
  typical: K_lo = 32, K_hi = 256

[BUCKET_THRESHOLD]
  bucket(n)        := ⌊log₁₀ n⌋         // decade bucket
  τ_b              := calibrated per bucket b
  PredictPrime(n)  := TRUE  ⟺
      MajorityVote_{w ∈ W}( |WaveValue_w(n)| ≤ τ_{bucket(n)} )

[ENSEMBLE_METRIC]
  F₁ᵢ  := Uᵣ[ 2·Pᵢ·Rᵢ / (Pᵢ+Rᵢ) ± δᵢ ]
  αᵢ   := F₁ᵢ / Σⱼ F₁ⱼ                   // normalized weight
  F₁_W := Σᵢ αᵢ · F₁ᵢ                    // weighted ensemble score

[MEMORY_BOUND]
  coeff table Cᵢ := {sin(kθᵢ), cos(kθᵢ)}   (2·Kᵢ floats per wave)
  ASSERT: Σᵢ 2·Kᵢ·8 bytes ≤ 4096 bytes    // kilobyte memory target

[JIT_HINT]
  JIT := TRUE  ⇒  use Numba/Cython kernel (wave evaluation only)
}WMC

[ USAGE_NOTES ]
  • Always verify memory budget: Σᵢ 2·Kᵢ·8 ≤ 4096 bytes before finalizing
    a WaveSet. Exceeding this breaks the kilobyte-scale design constraint.
  • Dynamic K (K_lo for small n, K_hi for large n) trades precision for speed
    where high Fourier order is unnecessary.
  • Majority vote requires an odd number of waves to avoid ties.
    With m=2, use weighted vote with α weights instead.
  • Report all individual F₁ᵢ values in the payload — not just F₁_W.
    The downstream analyzer uses the distribution, not just the aggregate.

[ SELF_CHECK ]
  Q1: A WaveSet has 4 waves with K = {32, 64, 128, 256}. What is the memory
      footprint? Does it fit within the budget?
      Expected: (32+64+128+256)·2·8 = 480·8 = 3840 bytes ≤ 4096 ✓

  Q2: Three waves vote {YES, NO, YES} on candidate n. What is the prediction?
      Expected: Majority = 2/3 → PredictPrime = TRUE → forward to Miller-Rabin.

  Q3: F₁ scores are Uᵣ[0.55±0.02], Uᵣ[0.60±0.02], Uᵣ[0.58±0.02].
      Compute α weights (approximate).
      Expected: Total ≈ 1.73; α₁ ≈ 0.318, α₂ ≈ 0.347, α₃ ≈ 0.335
               F₁_W ≈ 0.318×0.55 + 0.347×0.60 + 0.335×0.58 ≈ 0.578
