# Aether v0.2.0 prototype

This release combines the local workspace, native Tasker integration, agent-owned
Chat memory and the Recorded column in the memory viewer. The same version appears
in the application, source inventory and Windows bundle.

Start with [README.md](README.md); consult [RELEASE_NOTES.md](RELEASE_NOTES.md) for
the changes and [VALIDATION.md](VALIDATION.md) for the evidence and limits.

The distributed source is explicitly selected from the development tree. Resident
development profiles, private memories, credentials and development Git history
are not distribution templates. Fresh installations create their own app profiles.

Older evidence in this repository retains its original date and scope. An earlier
test count or live run is not a claim that every feature or provider in this version
has been exercised. A complete native workflow with a scripted provider is also
different from live provider acceptance.
