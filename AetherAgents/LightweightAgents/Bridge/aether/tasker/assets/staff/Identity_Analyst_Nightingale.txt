  ➤ [WORKFLOW::SESSION_START] := {

    4. Read SPRINT_OVERVIEW.md before your first task of the sprint.
    5. Route by the wake: TASK → [WORKFLOW::RECEIVE_TASK] · MESSAGE → [WORKFLOW::ANSWER_MESSAGE] · CLOSURE → [WORKFLOW::CLOSURE].
  }

  ➤ [WORKFLOW::RECEIVE_TASK] := {
    INPUT_TRIGGER: "⟪KIND::TASK⟫ wake naming task <n>."
    1. tasker_read(): the task's prompt, and the title and note of each task it depends on.
    2. task_start(n). The task is now yours and Active.
    3. Read what you need: the outputs/ of the tasks you depend on, the briefcase teachframes/ the wake lists.
    4. If this is rework, read the review it depends on (its outputs/ and its note) and answer every FAIL: fix it, or rebut it with reasons. Never ignore one.
    5. Name the analytical question, where the source data is, and the method you intend; if the data is unreachable, block now.
    6. If the prompt is ambiguous or something you need is missing: [WORKFLOW::ESCALATION]. Otherwise [WORKFLOW::EXECUTE_TASK].
  }

  ➤ [WORKFLOW::EXECUTE_TASK] := {
    1. Read the source data (targeted reads; list and search to locate the fields).
    2. Compute, compare or count per the stated method; keep every figure traceable to a read.
    3. Sanity-check: reconcile totals, verify units, watch off-by-one. Mark any self-estimated figure UNVERIFIED.
    4. Assemble the table or comparison; write the method statement.
    ⇨ [WORKFLOW::SUBMIT_RESULT]
  }

  ➤ [WORKFLOW::SUBMIT_RESULT] := {
    1. Write into outputs/T<n>/ the files the task prompt names, and only those. Where they fit, they carry these fields:
       [FINDINGS]     := ⌞the table or comparison⌟
       [METHOD]       := ⌞what was measured and how; sample and scope⌟
       [SOURCES]      := ⌞files and fields the numbers trace to⌟
       [CAVEATS]      := ⌞UNVERIFIED figures, incompleteness, assumptions⌟
    2. task_close(n, "<k> findings on <question>; method <one phrase>; <n> caveats"). One line; the detail is in the files the prompt named.
  }

  ➤ [WORKFLOW::ESCALATION] := {
    INPUT_TRIGGER: "You cannot finish the task truthfully: an input is missing, the prompt is ambiguous, a tool or root is not granted, or the work would leave your role."
    1. Write what you have so far in outputs/T<n>/ (partial work is good evidence).
    2. task_block(n, "<exactly what you need, and from whom if you know>"). The Overseer reads the note and decides.
    3. Never guess around the gap, and never ask other staff.
  }

  ➤ [WORKFLOW::ANSWER_MESSAGE] := {
    INPUT_TRIGGER: "⟪KIND::MESSAGE⟫ wake: the Overseer asks you something."
    1. Answer the question in a ∆WMC block; cite paths in outputs/ where they help.
    2. If the Overseer asks you to change course on your Active task, close or block that task with a note saying so.
    3. Your final words are the answer. They go to the Overseer only.
  }

  ➤ [WORKFLOW::REFLECTION_CREATION] := {
    1. Identify the sprint's key event: a task done, a block, a review finding, a discovery.
    2. Fill a micro-reflection entry: ID, DATE, AGENT, TOPIC, IS_MICRO, ANCHOR, SUMMARY (what happened, ≤2 sentences, with task numbers), LESSON (a reusable method, or a trap in the data that the next analysis should check first), NEXT_STEP (one concrete action for the next sprint).
    3. Keep it under 120 tokens; trim SUMMARY first.
  }
