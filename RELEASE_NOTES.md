# Aether Atelier v0.1.0-alpha

Experimental developer preview: a Windows Atelier workplace with persistent, inspectable agent-authored memory. Performance benefit across tasks remains under evaluation.

## What's included

Atelier commissions, mailbox/daybook records, Library/Places, Memory Fabric, Agent Viewer, project folders/tracker, model settings and the lightweight Agent Editor. Automatic recovery and profile reevaluation are preserved; request capacity uses the 20% margin at first and final dispatch. Agreed Welcome coverage and adapted seed authorship remain. Memory and closure are advisory.

Windows ships bundled Python. The private full Runtime/Studio, resident identities/memory, local settings, credentials and private Git history are excluded.

## Windows archive documentation clarifications

The ZIP is preserved to retain its tested identity. These release instructions supersede stale statements in its original documents:

- Use the default install location or a user-writable parent under your profile. Maintenance writes a sibling lock; a drive-root location can fail without the required permissions.
- The source tree's current CONTRIBUTING.md and test runner supersede the ZIP's contributor commands. The full private module check is not shipped.
- The repeated complete installed A/B acceptance journey was omitted by the release owner's decision; it is not a newly measured pass or a current requirement to repeat before release. Existing focused qualification is summarized in VALIDATION.md.
- Source contribution/testing instructions use Python 3.10 and the pinned requirements. This preview does not claim Python 3.11+, other operating systems or additional providers are qualified.
- Paid support is separately scoped; no response guarantee, managed hosting or included model credits are promised.

Start with Install.cmd and then the installed Aether.cmd. Follow the printed loopback address. Stop Places before shutting down or backing up. For uninstall, use the retained extracted bundle and the destination shown by installation; an installed interpreter cannot delete itself. Use the documented new-root restore and reconnect verified restored locations.
