[ TITLE ]
  Uncertainty Quantification (Uᵣ) for Numerical Streams

[ PURPOSE ]
  Establishes Uᵣ[μ ± ε] as the required notation for every numerical result
  produced or received in the Aether system. An uncertainty radius must
  accompany every computed value before it crosses an agent or tool boundary.
  After loading this frame, an agent can construct Uᵣ wrappers, propagate
  uncertainty through arithmetic, and pass conformant numeric payloads.

[ DEFINITIONS ]
∆WMC{
CONTEXT: NUMERIC_META
SUBJECT: UNCERTAINTY_RADIUS
[DEF]
  Uᵣ[μ ± ε]   := ⌞ordered pair (μ, ε) where μ is the computed value
                   and ε = |δ| is the absolute uncertainty radius⌟
  μ             := ⌞center value — the best estimate⌟
  ε             := ⌞uncertainty radius — non-negative; ε = 0 means exact⌟
[PROPERTIES]
  ⊨ Bound(μ, ε)  ⇒  ∀v ∈ ℝ : |v − μ| ≤ ε
  ⊩ Interval form: Uᵣ[μ ± ε]  ⇔  [μ − ε, μ + ε]
  ⊢₂ Truth(x)  ⇔  ε ≤ τ_layer       // layer-specific tolerance threshold
[PROPAGATION_RULES]
  // First-order safe propagation through arithmetic operations
  Uᵣ[a ± ε_a] + Uᵣ[b ± ε_b]   →  Uᵣ[(a + b)  ± (ε_a + ε_b)]
  Uᵣ[a ± ε_a] − Uᵣ[b ± ε_b]   →  Uᵣ[(a − b)  ± (ε_a + ε_b)]
  Uᵣ[a ± ε_a] × Uᵣ[b ± ε_b]   →  Uᵣ[(a × b)  ± (|b|·ε_a + |a|·ε_b)]
  Uᵣ[f(a ± ε_a)]               →  Uᵣ[f(μ_a)   ± |f′(μ_a)|·ε_a]
[ASSERT]
  ⊨ Every numeric result crossing a layer boundary MUST be wrapped in Uᵣ
  ⊨ ε is never dropped silently; if exact, write Uᵣ[μ ± 0]
}WMC

[ EXAMPLES ]
//
// Example 1 — Constructing Uᵣ from a truncated series
// Estimating ζ(2) by truncating the Dirichlet series at n = 10
//
Partial sum Σ₁¹⁰ = 1.54977
Tail bound ≈ ∫₁₀^∞ 1/x² dx = 1/10 = 0.1

Result := Uᵣ[1.54977 ± 0.1]        →  Interval: [1.44977, 1.64977]

//
// Example 2 — Propagating Uᵣ through addition
//
R₀  := Uᵣ[1.64493 ± 0.002]
term := Uᵣ[0.00826 ± 0.0001]

Sum  := Uᵣ[(1.64493 + 0.00826) ± (0.002 + 0.0001)]
     = Uᵣ[1.65319 ± 0.0021]

//
// Example 3 — Scaling by a constant
//
Uᵣ[2.001 ± 0.003] × 5
→ Uᵣ[10.005 ± 0.015]       // |f′(μ)| · ε = 5 × 0.003 = 0.015

[ USAGE_NOTES ]
  • Never collapse Uᵣ to a scalar during computation. Carry both μ and ε
    through every intermediate step; collapse only at final output or display.
  • When using compensated arithmetic (hi ⊕ lo terms), include the lo-term
    magnitude in ε: ε_out := ε_in ⊕ |lo|
  • ⊢₀ (Euler) stores results as (μ, ε) tuples.
  • ⊢₁ (Fibonacci) keeps the braid intact: Uᵣ wraps the ternary value ⊗(hi, lo).
  • ⊢₂ (Hypatia) converts Uᵣ to interval form for reconciliation. She will
    issue a REFINEMENT request if ε > τ⊢₂.
  • SBP payload template:
      PAYLOAD := Uᵣ[μ_value ± ε_bound]
      Include hi ⊕ lo if compensated arithmetic was used.
