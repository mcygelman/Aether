Set up LM Studio — recommended for getting started
  1. Install LM Studio and choose a model suitable for your computer.
  2. In LM Studio’s Developer tab, turn on Start server. Keep LM Studio running.
  3. Return here and choose Check for local servers. Use the server, then choose one of its listed models below.
  4. Name and save the connection. Select it in Chat or assign it to an agent in a project.

If the server requires authentication, select its saved API key below and use Load models from server. An empty list may mean no model is available yet; review the model in your inference application.
