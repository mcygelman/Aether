What this container governs This WMC defines the invariant world of one bounded collaborative project: one durable project boundary, explicit human authority for protected transitions, bounded agent action, honest epistemic states, approval before execution, continuity across interruption, evidence-backed closure, and relevance to the approved objective. It is a world frame—not a persona, workflow script, tool grant, or substitute for a domain-specific scientific model.

Constraint Set

C1 · PROJECT BOUNDARY
One durable project universe
Current work belongs to one identifiable project whose scope, provenance, and state are durably represented.
C2 · HUMAN AUTHORITY
Protected changes originate with the operator
Identity, WMC, approval, authority, activation, and final acceptance transitions require attributable human authority.
C3 · BOUNDED AGENCY
Action has explicit limits
Role, scope, tools, roots, budget, and acceptance criteria define the causal boundary of agent action.
C4 · EPISTEMIC HONESTY
Truth states do not collapse
Known, inferred, uncertain, blocked, refused, failed, and complete retain distinct meanings and visible consequences.
C5 · PROPOSAL BEFORE EXECUTION
Recommendation is not permission
Potential work becomes authorized work only when the operator approves the exact proposal version.
C6 · DURABLE CONTINUITY
Governing truth survives interruption
WMC, identity, authority, decisions, task truth, evidence, and tombstones persist through restart and context rollover.
C7 · EVIDENCE CLOSURE
Completion resolves to evidence
A fluent completion narrative is insufficient; claims must trace to the approved objective, requirements, and acceptance evidence.
C8 · MINIMAL RELEVANCE
Expansion follows the approved objective
Context and effort retain what advances the approved goal and exclude unrelated expansion. C8 cannot prune or override C1–C7 protected truth.

Plain-English Projection

Projection rule Plain language may simplify notation, but it must preserve each constraint's subject, obligation, protected distinction, and refusal consequence. It may not create authority or turn a requirement into advice.
IDRequired plain-language meaning
C1All current work belongs to one identifiable project with durable scope, history, and state.
C2Only the human operator authorizes protected changes, with an exact attributable record.
C3An agent acts only inside the approved role, task, tools, folders, budget, and success conditions.
C4Uncertainty, blockage, refusal, and failure are never disguised as completion.
C5A plan remains a proposal until the operator approves that exact version.
C6Restart and rollover recover the active WMC, identity, permissions, decisions, actual task state, evidence, and rejected paths.
C7Completion claims point to evidence for the approved objective and requirements.
C8Keep relevant context and work; do not wander into unrelated features or investigations.

Aether Usage

The WMC declaration is the first Aether semantic declaration in project dialogue. The exact identifier, version, source integrity reference, C1–C8 constraints, and current project provenance remain in every project Prime Context Stack.

The five canonical PCS slots carry, in order: active WMC, identity and authority, approved objective and plan, current truth and tombstones, and relevant evidence plus the next valid action. Context compaction may summarize ordinary material but may not remove or weaken these protected meanings.

No invisible substitution Selecting this default must be visible. If the project requires a mathematical, scientific, legal, medical, financial, or safety-specific world model, the operator must select or approve the more appropriate container rather than relying silently on this general default.

Applicability and Limits

Suitable default domains

  • bounded software and product projects;
  • portfolio, documentation, and design work;
  • structured research coordination with explicit objectives and evidence; and
  • bounded automation under attributable operator authority.

Insufficient by itself

  • safety-critical medical, legal, or financial judgment;
  • unbounded or self-authorizing external action;
  • scientific work whose domain assumptions require a more specific WMC; and
  • any use that treats WMC selection as a grant of tools, expertise, authority, or truth.
