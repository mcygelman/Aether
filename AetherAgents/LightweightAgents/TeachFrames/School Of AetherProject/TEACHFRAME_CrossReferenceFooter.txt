[ TITLE ]
  Cross-Reference Footer on Every Quick-Card and Reference

[ PURPOSE ]
  Teaches every agent to end any standalone quick-card or reference document with a one-line
  cross-reference footer linking its companion documents and the master card. Prevents orphaned
  documentation and lets a reader navigate the set from any single document without loading the
  whole protocol corpus.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[ DEFINITIONS ]
∆WMC{
CONTEXT: DOCUMENTATION_HYGIENE
SUBJECT: CROSS_REFERENCE_FOOTER
[DEF]
  QUICK_CARD       := ⌞a small standalone staff reference (one screen)⌟
  XREF_FOOTER      := ⌞a one-line footer naming companion docs + the master card⌟
[PROPERTIES]
  ⊨ Every standalone card/reference SHOULD end with an XREF_FOOTER
  ⊨ The footer is the LAST line; it adds ~one markdown line (~20 tokens)
  ⊨ Discoverability of the set MUST NOT depend on loading the full corpus
}WMC

[ EXAMPLES ]
//
// S00060/S00061 live evidence (the lesson's origin):
//
[Setup]:    Three learning-artifact quick-cards drafted independently (Micro-Reflection,
            TeachFrame Candidate, Resume Update).
[Process]:  All three shipped WITHOUT a footer; the gap recurred across independent drafts and
            again on the consolidated reference (S00061), each caught only at review.
[Result]:   → Promoted to doctrine: every card/reference ends with a footer naming its companions
            and the master Aether_v11_Staff_Quick_Card.md. Footer form below.

  Companion cards: <Card_A> · <Card_B> · <Card_C>. See the master Aether_v11_Staff_Quick_Card.md.

[ USAGE_NOTES ]
  • Builder: add the XREF_FOOTER as the final line of any standalone card/reference you produce.
  • Reviewer: treat a missing footer on a standalone card as a one-line REVISE finding.
  • Manager: when a card set grows, ensure footers list the current companions (update on add).
  • Scope: applies to standalone cards/references — NOT to task packets, results, or canvas entries.

[ SELF_CHECK ]
  Q: You finished a new standalone quick-card. What is its last line?
  A: A cross-reference footer naming its companion cards and the master card.
